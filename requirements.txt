# GPU INSTALL COMMANDS
# Run these IN ORDER after installing the CPU requirements above.
# Tested on: NVIDIA RTX 3050 Laptop, CUDA 12.4, Driver 551.61, Windows 10/11
# ══════════════════════════════════════════════════════════════════════════════
#
# STEP 1 — Replace CPU torch with CUDA 12.4 build (no-deps prevents
#          torch from being overwritten back to CPU by other packages):
#
#   pip install torch==2.4.0+cu124 torchvision==0.19.0+cu124 \
#       --index-url https://download.pytorch.org/whl/cu124 \
#       --force-reinstall --no-deps
#
# STEP 2 — Install ultralytics without deps (prevents it pulling CPU torch):
#
#   pip install ultralytics==8.3.0 --no-deps
#
# STEP 3 — Verify GPU is detected:
#
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
#   # Expected: 2.4.0+cu124  True  NVIDIA GeForce RTX 3050 Laptop GPU
#
# ── Notes ─────────────────────────────────────────────────────────────────────
#   - numpy must stay < 2.0 for torch 2.4.0 ABI compatibility
#   - ultralytics 8.3.0 excludes torch==2.4.0 on win32 in its metadata,
#     but it works correctly — use --no-deps to bypass the resolver
#   - YOLO inference runs in FP32 on GPU (half=False) due to a known
#     torch 2.4.0 Windows BatchNorm FP16 bug (ultralytics issue #15049)
#   - BiLSTM violence model and MobileNetV2 run in FP16 on GPU (no bug)
#   - For CUDA 11.8 machines replace cu124 with cu118 in the URLs above
# ══════════════════════════════════════════════════════════════════════════════
